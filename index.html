Cloud Computing

What is Cloud Computing?

Cloud computing means using the internet to store files and run programs on remote servers instead of only on your own computer. It lets people save, access, and share data online anytime without needing extra hardware.

Cloud Services

Google Drive

Used for storing files online and sharing documents, photos, and folders with other people.

Google Docs

Used for creating and editing documents online, and allows multiple people to work on the same file at the same time.

Dropbox

Used for backing up and storing files in the cloud so they can be accessed from any device with an internet connection.

Benefits of Cloud Computing

  • Access files from anywhere with an internet connection
  • Easily share and collaborate with other people
  • No need to buy extra storage hardware
  • Automatic backup of data
  • Can scale up or down depending on need
